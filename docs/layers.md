# Сцена, слои и камера

`pixel::Scene` — модуль ядра без SDL. Он хранит объекты с позицией, визуальными
частями и необязательным коллайдером. Рендерер приложения получает `drawList()`:
готовый список команд в порядке Background, Interactables, Characters, Foreground.
Для равных слоёв сортировка по order, затем стабильный порядок создания.

```cpp
pixel::Scene scene;
pixel::SceneObject tree;
tree.position = {20, 45};
tree.visuals = {
    {pixel::RenderLayer::Interactables, 10, {0, 0, 1, 10}, {100, 70, 40, 255}, 1},
    {pixel::RenderLayer::Foreground, 0, {-3, -2, 7, 4}, {40, 100, 50, 220}, 1}
};
tree.collider = pixel::Collider{{0, 0, 1, 10}};
auto id = scene.add(tree);
```

Визуальные прямоугольники и коллайдер задаются относительно позиции объекта.
`setPosition(id, position)` перемещает все его части и коллайдер вместе.
`setVisualVisible` скрывает часть без изменения физики; `setColliderEnabled`
управляет столкновениями без удаления изображений. `Scene::overlaps` фильтрует
коллайдеры по маскам групп и номеру физической плоскости. Границы, которые
только касаются друг друга, не считаются пересечением. Визуальные части с
parallax≠1 используйте для декораций: такие части смещаются относительно
обычного положения коллайдера при движении камеры.

Scene сейчас выдаёт прямоугольники с цветом; текстуры, скелеты и отрисовка
сетки World находятся в приложении. Персонаж рисуется отдельным силуэтом.
Камера хранит позицию и размер области просмотра в единицах мира:

```cpp
pixel::Camera camera(96, 72);
camera.follow({playerX + 1, playerY + 1.5f}, {128, 72});
auto screen = camera.worldToScreen({20, 45}, 1.0f);
auto world = camera.screenToWorld({mousePixelsX / 8.0f, mousePixelsY / 8.0f});
```

`follow` и `pan` ограничивают камеру границами мира. `moveTo` задаёт позицию
напрямую; приложение отвечает за выбор допустимой области. Преобразования
не меняют координаты мира, материалов или коллайдеров. Рендерер игры делает
пиксельное округление одинаково для картинки и мыши, оставляя накопление
перемещения камеры дробным. Его `mouseToWorld` используйте для игровой кисти.

В демо: горы находятся на фоне с параллаксом 0.25, ствол дерева — в слое
взаимодействия, ветки — впереди персонажа с параллаксом 1, кусты — на переднем
плане с параллаксом 1.15. Дерево — один объект с тремя визуальными частями.
Дверь имеет отдельный включаемый коллайдер и смену изображения.

Scene-коллайдеры пока участвуют в столкновениях персонажа. Симуляция веществ
World работает со своей сеткой: закрытая дверь не препятствует жидкости или
газу. Общий запрос препятствий для частиц и объектов — отдельный следующий
шаг, который должен сохранять массу при движении/закрытии препятствий.
Декоративные объекты сцены создаются из кода, в игровом сохранении записывается
состояние двери. Сериализация произвольной сцены пока не добавлена.

взаимодействия и сундук. Подробности: [interactions.md](interactions.md).
