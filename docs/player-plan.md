# Персонаж с руками и ногами: план следующего этапа

В версии 0.4 прямоугольник заменён простым силуэтом: голова, торс, плечи,
локти, кисти, колени и стопы. Ноги и руки визуально движутся при ходьбе,
при прыжке ноги поджимаются. Это основа изображения, а не физика конечностей.
Текущие столкновения и вытаптывание по-прежнему рассчитываются по прежнему
прямоугольнику тела и пройденному расстоянию. Поза пока не сохраняется:
она строится из состояния движения. Направление взгляда в покое пока вправо.

## 1. Вынести управление телом из игры в ядро

Добавить CharacterController без зависимости от SDL: позиция, скорость,
направление взгляда, grounded, запрос движения и прыжка. Оставить один основной
коллайдер для устойчивых столкновений с сеткой. Отдельно хранить Pose с точками
суставов; рендерер получает готовую позу. ECS и физический движок для этого
этапа не нужны. Добавить ускорение, торможение и сохранение направления взгляда.

При необходимости увеличить рост до 4–6 клеток: текущие 24 экранных пикселя
ограничивают детализацию рук и ног. Проверить высоту проёмов, прыжок и кисть
после изменения размеров, а не только растянуть картинку.

## 2. Контакт стоп и походка

Для каждой стопы хранить фазу «опора / перенос», точку контакта в координатах
мира и цель следующего шага. При опоре стопа остаётся на земле, тело движется
над ней. При переносе стопа проходит дугу до следующей точки. Поиск поверхности
делать лучом/коротким проходом по сетке под стопой; жидкости не считать твёрдой
опорой. На уступах, при исчезновении опоры и в прыжке освобождать контакт.

Двухзвенная обратная кинематика (бедро + голень) рассчитывает колено для
найденной стопы. Ограничивать цель длиной ноги и допустимыми углами. Основной
коллайдер решает движение тела; IK сначала влияет только на позу. Такой порядок
не даёт рукам/ногам раскачивать всё тело и делает отладку проще.

Каждое приземление стопы создаёт FootContact: точка, масса/нагрузка, импульс.
World::stepOn вызывается один раз на контакт, а не каждый кадр. Распределять
нагрузку между стопами; скорость и приземление усиливают нагрузку. Это свяжет
походку с уже реализованными влажностью и уплотнением почвы.

## 3. Руки и действия

Сначала добавить плечо/предплечье с ограничениями углов и противофазным махом.
Затем направлять кисть на цель инструмента двухзвенным IK, ограничивая досягаемость.
Отдельные коллайдеры рук нужны при появлении хватания или контакта с предметами.
Полноценный ragdoll добавлять позже для падений; он не требуется для ходьбы.

## 4. Проверки и сохранения

Проверять: стопа не проходит под землю, опорная стопа не скользит, колено не
перегибается, тело не проходит через стены, персонаж может сойти с уступа,
контакты не дублируются при разной частоте рендера. После загрузки должны
восстанавливаться скорости, направление, фаза шага и закреплённые стопы.
Для новых состояний поднять версию игрового заголовка и сохранить чтение v1.

Первый проверяемый результат следующего этапа: персонаж стоит двумя стопами
на ровной поверхности, идёт без скольжения и оставляет след именно под стопой.
