# Game art

`oak.png` — original oak sprite generated for StartApp2 using image generation.
It is a transparent RGBA PNG. The renderer samples it with nearest-neighbour
filtering; a normalized source region can be drawn again in the foreground.
The PNG is loaded once and shared between tree instances.

Keep the entire assets directory beside PixelSandbox.exe / PixelSandbox.

fonts/DejaVuSans.ttf supplies Cyrillic glyphs for PixelStudio. Its redistribution
notice is included as fonts/LICENSE.txt. The editor's sample flame is generated
by the C++ example-project code and stored as editable frames in .pxproj files.
