StartApp2 / PixelSandbox — Linux x86_64

Extract the entire archive. In a terminal in this folder:
  chmod +x StartGame.sh PixelSandbox
  ./StartGame.sh

Requires a graphical desktop, glibc 2.31+ and the SDL2 runtime library.
Ubuntu/Debian: sudo apt install libsdl2-2.0-0
Fedora: sudo dnf install SDL2
Arch: sudo pacman -S sdl2
No compiler is needed to run the binary package.

A/D or arrows: move. Space: jump.
1 sand, 2 water, 3 gas, 4 stone, 5 soil, 6 erase.
Left mouse: paint; right mouse: erase.
P pause; F world speed x30; R reset; F5 save; F9 load; Escape quit.

Diagnostics: SDL_VIDEODRIVER=dummy ./StartGame.sh --smoke-test
If your distribution cannot load the binary, build from source; see README.md.

Save slot: ~/.local/share/PaperGoose/PixelSandbox/quick-save.pxs
(or the XDG_DATA_HOME directory). F5 saves; F9 restores after restart.

Version 0.4: soil absorbs water; wet soil darkens. Hover soil for wetness.
Walk over the dry patch on the left, then water it with brush 2.
F speeds up growth and absorption. Player limbs are visual only for now.

Version 0.5: E opens/closes the nearby gate; C toggles camera follow.
J/L pan when follow is off. Tab toggles foreground decoration.
Saves include the gate. Old saves remain readable with the gate open.
