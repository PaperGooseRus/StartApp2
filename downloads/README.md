# Скачать версию 0.6

Пакеты 0.6 собраны из исходников коммита `0b06f2b`.

- [Windows 10/11 x64](PixelSandbox-v0.6-Windows-x64.zip): распакуйте весь архив, запустите `StartGame.bat`. `CheckGame.bat` выполняет проверки.
- [Linux x86_64](PixelSandbox-v0.6-Linux-x64.zip): распакуйте, выполните `chmod +x StartGame.sh PixelSandbox`, затем `./StartGame.sh`.
- [Исходники 0.6](StartApp2-v0.6-source.zip): ядро, игра, ресурсы и тесты. Без вложенных бинарных архивов.

Новое: ближайшая доступная цель взаимодействия, рамка и подсказка E, дверь и сундук, сохранение обоих состояний, PNG-спрайты дубов с прозрачностью и общим кэшем. Сундук пока без инвентаря.

Распаковывайте весь архив: **assets должен оставаться рядом с программой**.
Подойдите к двери (x=36) или сундуку (x=69) и нажмите E. A/D — ходьба, пробел — прыжок, F5/F9 — сохранение/загрузка. C — камера, J/L — ручное перемещение, Tab — передний план.

Linux: нужны графический сеанс, glibc 2.31+ и SDL2 runtime (`sudo apt install libsdl2-2.0-0` для Debian/Ubuntu). SDL2.dll для Windows включена.

Пять наборов тестов прошли на Linux, в том числе PNG-отрисовка. Проверка игры с AddressSanitizer/UndefinedBehaviorSanitizer прошла. Windows-пакет собран кросс-компилятором; запуск на настоящей Windows пока не подтверждён.
Старые сохранения 0.3–0.5 читаются; старые версии игры не читают новый игровой заголовок v3.
Контрольные суммы — [SHA256SUMS.txt](SHA256SUMS.txt).
