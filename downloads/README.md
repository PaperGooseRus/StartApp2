# Скачать версию 0.5

Пакеты 0.5 собраны из исходников коммита `2314162`.

- [Windows 10/11 x64](PixelSandbox-v0.5-Windows-x64.zip): распакуйте весь архив, запустите `StartGame.bat`. `CheckGame.bat` проверяет физику, почву, сцену, сохранения и отрисовку.
- [Linux x86_64](PixelSandbox-v0.5-Linux-x64.zip): установите SDL2 runtime, распакуйте архив, выполните `chmod +x StartGame.sh PixelSandbox`, затем `./StartGame.sh`.
- [Исходники 0.5](StartApp2-v0.5-source.zip): ядро, игра, тесты и инструкции сборки. Архив исходников не содержит бинарные пакеты из папки downloads.

Linux: `sudo apt install libsdl2-2.0-0` для Ubuntu/Debian. Нужны графический сеанс и glibc 2.31+.

Новое: четыре слоя сцены, камера и параллакс. E открывает дверь, C переключает слежение камеры, J/L двигают свободную камеру, Tab показывает/скрывает передний план.

A/D — ходьба, пробел — прыжок, 1–6 — материалы, мышь — кисть, F — ускорение, F5 — сохранение, F9 — загрузка. Сохраняется состояние двери; старые сохранения 0.3/0.4 поддерживаются.

Пять наборов тестов прошли на Linux. Windows-пакет собран кросс-компилятором; запуск на настоящей Windows пока не подтверждён.
Контрольные суммы всех архивов — [SHA256SUMS.txt](SHA256SUMS.txt).
